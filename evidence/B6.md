To rerun the keyboard proof, start Fieldbook with a disposable PostgreSQL 16 database, filesystem media mount and virtual-passkey-capable Chromium. Set `FIELDBOOK_TEST_ORIGIN` and `FIELDBOOK_TEST_DATABASE_URL` for the loopback app and database. Run `npm --prefix web run test:projects`. For the restore part, also start a separate instance with an empty database, empty media directory and separate temporary session secret. Set `FIELDBOOK_TEST_RESTORE_ORIGIN`, `FIELDBOOK_TEST_RESTORE_DATABASE_URL`, `FIELDBOOK_TEST_SOURCE_MEDIA` and `FIELDBOOK_TEST_RESTORE_MEDIA`. The acceptance script refuses to restore over an initialized database or a nonempty media directory. It dumps data without passkeys, enrollment grants, ceremonies or sessions, copies the referenced original files, and signs in again through the second app.
