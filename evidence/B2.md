# B2 journal rehearsal and T2 result

**T2 passed locally.** The production Rust server served the built Svelte client and used disposable PostgreSQL 16.16 databases. The clean implementation base was `37bc68a8479e5f9b0273e96e0f82916d8b4a55dd`. The separate T1 evidence edits were present at the start and stayed untouched. The tested B2 implementation is recorded in candidate `02dff51173958455b780801e031b58b140d19cca`.

## Observations

| --- | --- |

A request containing an unknown attachment rolled back the whole save, and the second household could not attach that asset. |

Switching accounts cleared the old draft in both tabs. Browser storage stayed empty. |
| B2.3 voice and comments | A guardian’s dated suggestion displayed the guardian’s signed identity and left learner prose unchanged. A guardian could withdraw and restore their suggestion under the same ID. The guardian received the scoped 404 when attempting to change learner prose. An independent guardian observation retained its selected learner and activity date. |
| B2.3 scribed confirmation | A guardian recorded the learner’s spoken words. The authenticated learner confirmed revision 1, corrected the words, and saw a new unconfirmed revision. The learner confirmed and then withdrew revision 2 explicitly. |
| B2.3 journal isolation | A different synthetic household received the same 404 response for the other family’s moment, revision list and comment list as for an absent record. |
| Browser form route | A form-encoded request with an invalid activity date returned 422 and the submitted note. A valid request followed a redirect to the authorized moment screen. The UI’s ordinary JSON save also returned 201 and the stable moment. |
| T2 combined | The learner saved without a photo, project, or guardian. Double submission saved once. A parent posted a suggestion under their own identity. The learner recovered the original attributable wording, and invalid input retained the typed text. |

After the browser run, all four migrations showed success. The dedicated T2 household contained one guardian observation at revision 1, one scribed moment at revision 2, the original student moment at revision 4 and a separate student moment from the form check at revision 1. The suggestion was active after restoration. Both historical confirmation rows had withdrawal timestamps.

The family editor keeps unsaved drafts in tab memory. The form-encoded validation path was exercised via browser fetch. Native document navigation after a rejected form submission remains untested. The successful form redirect contains an opaque moment ID and the app checks access before displaying the record. Upload finalization, original file downloads, and photo picking are B3 work. Diary and invited relative sharing are later tickets. The hosted workflow was updated to run the new checks and will exercise the candidate after it reaches GitHub. The outstanding T1 native credential rehearsal has its own receipt.
