Design v0.8 · Acceptance T20 · Primary lane access

Preserve one source across multiple projects and views.

Add Portfolio, optional approximate event dates, multi-project evidence links and explicit selections. Preserve Keepsakes links.

## Assign one slice

### B20.1 · Select a portfolio source

**Suggested change area** SQL. **Prerequisites** B3.3, B5.2, B6.2, B9.2.

Support approximate dates, backfill and an explicit, unique learner/moment portfolio selection.

**Inputs and suggested files** fixtures/household.json. migrations/, crates/fieldbook/src/storage/ and SQL-backed integration tests.

**Run** Run cargo test --workspace --locked with an isolated PostgreSQL 16 database. Inspect committed rows and original file hashes where relevant.

**Passing example** A month-only participation can be entered without a file. Replay creates one selection.

**Counterexample** Removing a selection keeps the original moment, its attribution, files and additional project links.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B20.2 · Connect a past and a new achievement

**Suggested change area** UI. **Prerequisites** B20.1.

Show event vs recording dates, My part, recognized result, help and optionally a teacher PDF. Link by existing moment ID.

**Inputs and suggested files** fixtures/household.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** One actual trial links to two projects, with one dated source, and the original teacher letter can be added later.

**Counterexample** Checking off an idea or saving a rehearsal creates no achievement or new moment.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B20.3 · Round-trip a schema-5 portfolio

**Suggested change area** QA. **Prerequisites** B20.2.

Check the legacy selection, writing pointer, PDF snapshots and link identities through restore and guest preview.

**Inputs and suggested files** fixtures/household.json. The relevant integration or device tests and their evidence.

**Run** Drive the named application flow against a disposable fixture. Run the owning Rust or web suite plus the specified device or operator procedure.

**Passing example** After restore the same eligible guest sees only the approved photo highlight.

**Counterexample** Withdrawing a portfolio item or revoking a grant never destroys another project’s source.

**Suggested model** GPT-6.2 Sol for the integration or review.
