## Assign one slice

### B9.1 · Select and approve fields

**Suggested change area** Rust. **Prerequisites** B5.2, B6.2.

Build the one-page selector and approval states for both audience templates, preserving student voice and My part.

**Inputs and suggested files** fixtures/household.json. crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** A mentor preview opens with the question and contains only approved, versioned text and chosen records.

**Counterexample** Changed source permissions or stale approval require review before a fresh outward edition.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B9.2 · Render and freeze a page

**Suggested change area** UI. **Prerequisites** B9.1.

Use one renderer for preview, print and a frozen edition. Keep private assets immutable with version and attribution.

**Inputs and suggested files** fixtures/household.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** Both formats fit one Letter page, and an earlier frozen page remains readable after editing a source.

**Counterexample** Overlong content requests editing or selection review. A private sentinel or unapproved letter cannot appear.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B9.3 · Replay a change in audience

**Inputs and suggested files** fixtures/household.json. The relevant integration or device tests and their evidence.

**Suggested model** GPT-6.2 Sol for the integration or review.
