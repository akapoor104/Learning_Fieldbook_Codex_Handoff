## Assign one slice

### B3.1 · Finalize private copies

**Suggested change area** Storage. **Prerequisites** B2.1.

Store staged chunks, resume by offset, verify length and SHA-256, and publish immutable originals before making their relation visible.

**Inputs and suggested files** fixtures/assets.json. migrations/, crates/fieldbook/src/storage/ and SQL-backed integration tests.

**Run** Run cargo test --workspace --locked with an isolated PostgreSQL 16 database. Inspect committed rows and original file hashes where relevant.

**Passing example** Interrupt and resume a copy. The final original opens once with the manifest hash.

**Counterexample** A missing or changed chunk leaves no ready original or public preview. A replay creates no duplicate file.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B3.2 · Match a photo from another device

**Suggested change area** UI. **Prerequisites** B3.1.

Implement parent photo/file picker, Family photos to match, explicit match and unmatch, actor attribution and independent assets.

**Inputs and suggested files** fixtures/assets.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** Test words-first and photo-first, using two accounts. One asset and the original uploader remain after unmatching and relinking.

**Counterexample** A parent cannot attach to the child’s diary. A duplicate match makes one relation.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B3.3 · Separate Drive links and copies

**Suggested change area** API. **Prerequisites** B3.2.

Support an ordered list of mixed assets, private original downloads and a user-supplied original for Keep a copy.

**Inputs and suggested files** fixtures/assets.json. crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** Four local files open with Drive disconnected. The fifth clearly says link-only until a verified copy completes.

**Counterexample** A private PDF stays unavailable to a guest who was granted the separate photo.

**Suggested model** GPT-6.2 Sol for the integration or review.
