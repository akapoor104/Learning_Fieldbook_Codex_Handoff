## Assign one slice

### B1.1 · Bind identity to a household

**Suggested change area** Rust. **Prerequisites** B0.2.

Implement server-verified WebAuthn enrollment and sign-in with the maintained library. Bind sessions to actor and household and verify origin, CSRF and per-record policy.

**Inputs and suggested files** fixtures/household.json. crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** The learner signs in with a device credential or security key and two guardians sign in separately.

**Counterexample** An unrelated household receives the same 404 for absent and inaccessible private records.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B1.2 · Switch accounts on a shared computer

**Suggested change area** UI. **Prerequisites** B1.1.

Create a phone-free sign-in entry, visible current actor, sign-out, switch account and empty Home with keyboard focus.

**Inputs and suggested files** fixtures/household.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** At 360 px and 200% zoom the writer can reach capture, sign out, and enter as a different family member.

**Counterexample** After switching, Back and browser cache reveal no previous actor’s text or draft.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B1.3 · Rehearse learner and parent entry

**Suggested change area** QA. **Prerequisites** B1.2.

Exercise the shared computer and a guardian’s Android flow with fictional data. Save keyboard order and actual device or emulator used.

**Inputs and suggested files** fixtures/household.json. The relevant integration or device tests and their evidence.

**Run** Drive the named application flow against a disposable fixture. Run the owning Rust or web suite plus the specified device or operator procedure.

**Passing example** Separate signed sessions can reach their allowed Home and a parent can reauthenticate independently.

**Counterexample** Record virtual and physical credential tests separately. Expired sessions request sign-in and clear local sensitive state.

**Suggested model** GPT-6.2 Sol for the integration or review.
