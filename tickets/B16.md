## Assign one slice

### B16.1 · Describe a named input and output

**Suggested change area** SQL. **Prerequisites** B15.1.

Attach meaning, revision, units or format, sample and acceptance criteria to an endpoint. Pin accepted versions.

**Inputs and suggested files** fixtures/beat-pattern.json. migrations/, crates/fieldbook/src/storage/ and SQL-backed integration tests.

**Run** Run cargo test --workspace --locked with an isolated PostgreSQL 16 database. Inspect committed rows and original file hashes where relevant.

**Passing example** One output can supply two different consumers and a node can receive two separately named inputs.

**Counterexample** A second active producer cannot occupy one ordinary required input.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B16.2 · Validate required dependencies

**Suggested change area** Rust. **Prerequisites** B16.1.

Serialize handoff changes per map, evaluate required same-pass cycles on the full authorized project and keep next-pass feedback separate.

**Inputs and suggested files** fixtures/beat-pattern.json. crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** Acyclic dependencies commit and labeled next-pass feedback may form an intentional loop.

**Counterexample** Reject required cycles even when an endpoint sits outside the visible page. No cross-household link is accepted.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B16.3 · Connect and disconnect a handoff

**Suggested change area** UI. **Prerequisites** B16.2.

Show named source and consumer, the sample and its version. Implement removal/restore through the shared recovery contract.

**Inputs and suggested files** fixtures/beat-pattern.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** A reader can tell what is provided and how to check it without opening the whole project.

**Counterexample** Disconnecting an interface cannot delete either producer or consumer.

**Suggested model** GPT-6 Luna for a bounded implementation or test.
