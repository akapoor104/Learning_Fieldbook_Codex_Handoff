# B2 · Journal

Design v0.8 · Acceptance T2 · Primary lane product

The journal is usable before any photo, tag or project is available.

## Outcome

Text or photo capture, default family journal, own-word edits and scribed confirmation, dated comments.

## Read only what you need

Use the numbered paragraphs in `reference/Learning_Fieldbook_Design_Spec_v0.8.md`, lines 96-118,415-450. Shared API decisions are in `contracts/README.md`. Scenarios S1, S2, S3, S6, S11.

## Assign one slice

### B2.1 · Save one attributed sentence

**Suggested change area** SQL. **Prerequisites** B1.1, B1.2.

Implement the moment command, unique actor/submission key, optional activity date and optimistic revisions. Support text or a finalized file.

**Inputs and suggested files** fixtures/household.json. migrations/, crates/fieldbook/src/storage/ and SQL-backed integration tests.

**Run** Run cargo test --workspace --locked with an isolated PostgreSQL 16 database. Inspect committed rows and original file hashes where relevant.

**Passing example** One sentence saves without a project. A duplicate submission returns the same moment and keeps authorship.

**Counterexample** Reject an empty note with no finalized file. A stale revision preserves both versions for review.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B2.2 · Capture and keep a draft

**Suggested change area** UI. **Prerequisites** B2.1.

Build the solo sentence editor and family mode. Keep a draft tied to tab, actor and intended object until saved or discarded.

**Inputs and suggested files** fixtures/household.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** Two tabs can change selection independently while the first retains its typed words and parent.

**Counterexample** A validation error preserves words. A switch of account removes access to the previous actor’s draft.

**Suggested model** GPT-6 Luna for a bounded implementation or test.

### B2.3 · Comment without changing the child’s words

**Suggested change area** Rust/UI. **Prerequisites** B2.2.

Implement own-word edits, signed family comments, guardian observations and confirmation for scribed words.

**Inputs and suggested files** fixtures/household.json. crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** A parent can comment under their own name and Anush can confirm or correct a scribed draft.

**Counterexample** An adult comment cannot rewrite student prose. Editing scribed wording clears earlier outward approval.

**Suggested model** GPT-6.2 Sol for the integration or review.

## Accept the complete ticket

**T2.** Anush saves a sentence without a photo or guardian. A double-tap saves one entry. A parent can add a suggestion as a comment. Only the learner can revise the learner’s own words, and the original version remains attributable. Invalid input retains typed text.

Runnable adapter cases in `validation/cases.json` include ‘journal-retry’.
