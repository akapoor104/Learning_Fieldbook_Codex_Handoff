## Assign one slice

### B6.1 · Store attempts and contributions

**Suggested change area** SQL. **Prerequisites** B2.3, B3.2.

Add optional roles, event/outcome, help credits, prior attempt and editable household labels with stable IDs.

**Inputs and suggested files** fixtures/household.json. migrations/, crates/fieldbook/src/storage/ and SQL-backed integration tests.

**Run** Run cargo test --workspace --locked with an isolated PostgreSQL 16 database. Inspect committed rows and original file hashes where relevant.

**Passing example** A scout, artist, athlete or new family-defined project uses the same save path. Old attempts remain independent.

**Counterexample** Retiring a label hides it from new choices and preserves historical links.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B6.2 · Compare two attempts

**Suggested change area** UI. **Prerequisites** B6.1.

Display event chronology, contributions, help and outcomes. Allow an existing family moment to link to another project or skill by ID.

**Inputs and suggested files** fixtures/household.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** Two attempts display in activity order. One revised moment supports two skills with separate reasons.

**Counterexample** Removing one connection never deletes the source, its files or its other project.

**Suggested model** GPT-6 Luna for a bounded implementation or test.

### B6.3 · Trace a transfer

**Suggested change area** QA. **Prerequisites** B6.2.

Seed two comparable attempts in different domains. Capture the learner’s reason for transferring a skill and the attribution.

**Inputs and suggested files** fixtures/household.json. The relevant integration or device tests and their evidence.

**Run** Drive the named application flow against a disposable fixture. Run the owning Rust or web suite plus the specified device or operator procedure.

**Passing example** Following either project or skill returns the same source ID and its evidence sentence.

**Counterexample** One suggestion alone adds no demonstrated skill. Test a project with no configured domain label.

**Suggested model** GPT-6 Luna for a bounded implementation or test.
