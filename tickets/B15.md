## Assign one slice

### B15.1 · Commit one outline split

**Suggested change area** Rust. **Prerequisites** B13.2.

Implement ordered children with stable IDs. Validate revision and actor-scoped idempotency in one transaction.

**Inputs and suggested files** contracts/planning-examples.json. crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** From revision 12 an accepted split returns revision 13, two ordered IDs and selects the first. A retry replays 201 and those IDs.

**Counterexample** A changed payload under the old key or stale revision yields 409. Blank titles yield 422 with no partial children.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B15.2 · Insert, move and split in List

**Suggested change area** UI. **Prerequisites** B15.1.

Implement first idea, sub-idea, before/after, split preview, cancel, collapse and accessible move up/down or change parent.

**Inputs and suggested files** contracts/planning-examples.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** Select a new child and split into grandchildren. Insert a sibling between two existing rows. Right-click, visible menu and keyboard expose the same actions.

**Counterexample** Cancel changes nothing. Reject a move into a descendant and preserve the parent’s references and handoffs.

**Suggested model** GPT-6 Luna for a bounded implementation or test.
