# B18 · Ordered writing

Design v0.8 · Acceptance T18 · Primary lane product

Google Docs is opened by the user. Manuscript text stays in their chosen document.

## Outcome

Build the essay plan, restricted Google Docs link, optional archived PDF and reverse outline.

## Read only what you need

Use the numbered paragraphs in `reference/Learning_Fieldbook_Design_Spec_v0.8.md`, lines 318-340,464-483,694-706. Shared API decisions are in `contracts/README.md`. Scenarios S20.

## Assign one slice

### B18.1 · Reorder an essay plan

**Suggested change area** UI. **Prerequisites** B15.2, B3.1.

Add paragraph purpose, source reference, reader order and reverse-outline note. Track old and new adjacent transition flags.

**Inputs and suggested files** fixtures/archive-vectors.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** Move a body section before the opening. Each section appears once and both affected joins are flagged.

**Counterexample** Changing reader order does not manufacture an input/output dependency or discard evidence.

**Suggested model** GPT-6 Luna for a bounded implementation or test.

### B18.2 · Validate a Docs pointer

**Suggested change area** Rust. **Prerequisites** B18.1.

Accept a restricted-document HTTPS pointer on the exact docs.google.com document path. Store user-supplied title and open with no referrer.

**Inputs and suggested files** fixtures/archive-vectors.json. crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** Replace a document pointer while retaining the plan, and display a useful missing-access state.

**Counterexample** Reject unsupported origins and credential-bearing links. Saving or restoring a pointer makes zero fetches.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B18.3 · Retain a dated writing snapshot

**Suggested change area** QA. **Prerequisites** B18.2, B3.3.

Link a private archived PDF and migrate a schema-4 paragraph as exact read-only legacy text with its author and ID.

**Inputs and suggested files** fixtures/archive-vectors.json. The relevant integration or device tests and their evidence.

**Run** Drive the named application flow against a disposable fixture. Run the owning Rust or web suite plus the specified device or operator procedure.

**Passing example** After changing the link the earlier PDF opens with its original hash.

**Counterexample** Typographic punctuation and line breaks match character for character. The migrated Docs pointer starts empty.

**Suggested model** GPT-6 Luna for a bounded implementation or test.
