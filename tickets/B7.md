## Assign one slice

### B7.1 · Match one earlier moment

**Suggested change area** Rust. **Prerequisites** B6.2, B4.1.

Rank authorized family candidates by common skill, recent activity date and stable ID. Record dismissals.

**Inputs and suggested files** fixtures/household.json. crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** Return at most one related moment with a reason, or no match on unrelated history.

**Counterexample** A dismissed pair, diary or inaccessible moment never appears and never affects displayed counts.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B7.2 · Keep one small experiment

**Suggested change area** UI. **Prerequisites** B7.1.

Add Explore to a moment and check-in, one proposed experiment and an optional exact quotation from a verified, versioned catalog.

**Inputs and suggested files** fixtures/household.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** A learner can accept, skip or simply keep the memory. A good match shows author, source and context.

**Counterexample** No match still allows a small experiment. No verified quote means no quote card.

**Suggested model** GPT-6 Luna for a bounded implementation or test.

### B7.3 · Resume after a skipped week

**Suggested change area** SQL/QA. **Prerequisites** B7.2.

Persist one check-in per learner/local week, most recent chosen next action and any observed outcome.

**Inputs and suggested files** fixtures/household.json. The relevant integration or device tests and their evidence.

**Run** Drive the named application flow against a disposable fixture. Run the owning Rust or web suite plus the specified device or operator procedure.

**Passing example** Skip a week and retrieve the previous nonblank next step without a backlog.

**Counterexample** Repeated save in the same week updates one check-in. Merely browsing never silently changes a chosen action.

**Suggested model** GPT-6.2 Sol for the integration or review.
