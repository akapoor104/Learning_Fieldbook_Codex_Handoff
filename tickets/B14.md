## Assign one slice

### B14.1 · Store a chosen experiment

**Suggested change area** Rust. **Prerequisites** B13.2, B7.2.

Implement one experiment with up to three editable steps and a student-chosen next action. Keep park/resume reversible.

**Inputs and suggested files** fixtures/archive-vectors.json. crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** Park and reopen a project. The chosen step remains recoverable even after looking at another card.

**Counterexample** Marking a step complete or sampling a contract creates zero journal or portfolio records.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B14.2 · Record what happened once

**Suggested change area** UI. **Prerequisites** B14.1.

Create a learner-attributed moment from explicit recording and allow a help card with tried/stuck/question fields.

**Inputs and suggested files** fixtures/archive-vectors.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** A repeated successful recording returns the same source ID and lets the student keep a failed trial.

**Counterexample** An unsent help preview contacts nobody. Cancel preserves the plan.

**Suggested model** GPT-6 Luna for a bounded implementation or test.

### B14.3 · Restore earlier maps

**Suggested change area** QA. **Prerequisites** B14.2.

Run schema 2 and 3 migration vectors and demonstrate one resumed experiment with its original provenance.

**Inputs and suggested files** fixtures/archive-vectors.json. The relevant integration or device tests and their evidence.

**Run** Drive the named application flow against a disposable fixture. Run the owning Rust or web suite plus the specified device or operator procedure.

**Passing example** Schema 2 has empty maps. Schema 3 keeps edges/steps and the recorded root or a deterministic root placement.

**Counterexample** An old creative link never becomes an inferred dependency or second outline parent.

**Suggested model** GPT-6 Luna for a bounded implementation or test.
