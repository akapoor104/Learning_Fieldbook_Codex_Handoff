## Assign one slice

### B19.1 · Read a bounded neighborhood

**Suggested change area** Rust. **Prerequisites** B13.2, B15.2, B16.2.

Return one focused node and up to 24 authorized neighbors, typed edge IDs, revision, selection and an opaque continuation.

**Inputs and suggested files** contracts/planning-examples.json. crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** The worked graph fixture renders after filtering both endpoints before counts and pagination.

**Counterexample** Inaccessible sources add no names, hidden counts, cursors revealing hidden records, or edges.

**Suggested model** GPT-6.2 Sol for the integration or review.
