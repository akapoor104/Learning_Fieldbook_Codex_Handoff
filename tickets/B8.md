Design v0.8 · Acceptance T8 · Primary lane access

## Outcome

Provider interface, eligibility/configuration control, exact-text preview, explicit send, labeled result, error fallback.

## Assign one slice

### B8.1 · Put the external adapter behind a switch

**Suggested change area** Rust. **Prerequisites** B7.1, B4.2.

Define provider inputs, labeled outputs, guardian enablement, eligible configuration and local fallback.

**Inputs and suggested files** validation/cases.json (ai-cancel). crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** Disabled and canceled paths complete locally with zero outbound calls.

**Counterexample** Missing eligibility or failed service returns a local suggestion without resending private material.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B8.2 · Confirm the exact excerpt

**Suggested change area** UI. **Prerequisites** B8.1.

Preview provider name and precise editable excerpt. Bind consent to actor, provider, text/version and expiry.

**Inputs and suggested files** validation/cases.json (ai-cancel). web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** One explicit send supplies only previewed personal text and a fixed instruction.

**Counterexample** Editing the excerpt invalidates approval. No files, relatives’ names, graph or hidden notes join the request.

**Suggested model** GPT-6.2 Sol for the integration or review.

### B8.3 · Count requests and validate fallback

**Suggested change area** QA. **Prerequisites** B8.2.

Exercise disable, cancel, timeout, duplicate confirm and unusable response with a recording fake.

**Inputs and suggested files** validation/cases.json (ai-cancel). The relevant integration or device tests and their evidence.

**Run** Drive the named application flow against a disposable fixture. Run the owning Rust or web suite plus the specified device or operator procedure.

**Passing example** One confirmed idempotent request produces one labeled result of the correct visibility.

**Counterexample** The guardian’s exceptional diary view cannot send anything. Logs omit excerpt text.

**Suggested model** GPT-6.2 Sol for the integration or review.

## Accept the complete ticket

**T8.** With a fake service, disabled or canceled means zero requests. On confirmed send, the only personal input exactly matches the preview. A rejected or timed-out request yields a local suggestion. Runs in synthetic mode until a real service qualifies.

Runnable adapter cases in `validation/cases.json` include ‘ai-cancel’.

Record commands, actual outputs, test environment and evidence files. Attach the normal and adverse observations and the result of the full T case. An unchecked claim remains untested. Use `python3 tools/fieldbook.py template B8` to generate the pending receipt after implementation.
