## Assign one slice

### B12.1 · Choose one borrowed method

**Suggested change area** Rust. **Prerequisites** Ready from unpacking.

Implement a pure choose_lens function over the supplied records. Filter different field, matching mechanism, feasible materials/time, requested field and dismissed version. Apply stable tie-breaking.

**Inputs and suggested files** fixtures/lens.json. An isolated Rust domain module and its Cargo unit tests.

**Run** Run cargo test against the new selection rule. Compare the four lens cases using the same inputs as the demonstration.

**Passing example** The grouping seed returns the rhythm lens in fixtures/lens.json. Empty or dismissed choices yield no suggestion.

**Counterexample** The navigation lens does not match grouping. No network, database, identity or phone is needed.

**Suggested model** GPT-6 Luna for a bounded implementation or test.

### B12.2 · Explain a borrowed method

**Suggested change area** UI. **Prerequisites** B12.1.

Render one local card with its bridge, limitation and small test. Support keep, skip, retry and write my own, including keyboard control.

**Inputs and suggested files** fixtures/lens.json. web/src/ and web/tests/.

**Run** From web/, run npm run check, npm test and npm run build. Exercise the named control with a keyboard.

**Passing example** With the fixture the learner can explain why the music method applies and edit it before keeping.

**Counterexample** An exhausted deck opens the own-idea path, produces no persisted draft and makes no outside request.

**Suggested model** GPT-6 Luna for a bounded implementation or test.

### B12.3 · Save the accepted version

**Suggested change area** Rust/UI. **Prerequisites** B12.2, B1.1, B2.1.

Connect the Rust response to the Svelte card. Persist accepted version and edits within an authorized map when B13 lands.

**Inputs and suggested files** fixtures/lens.json. crates/fieldbook/src/ and crates/fieldbook/tests/, plus web/src/ for a joint UI slice.

**Run** Run cargo fmt --all -- --check and cargo test --workspace --locked. For a UI join also run the relevant web tests.

**Passing example** One request shows one result. Keep preserves provenance, skip suppresses that version for the same starting idea.

**Counterexample** A reissued request or reload cannot create a second accepted card. B12.3 needs B1.1 and B2.1 for the production join.

**Suggested model** GPT-6.2 Sol for the integration or review.
